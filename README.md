# Mini Projects

A collection of small programming projects and experiments created while learning software development. The repository is a work in progress and focuses on practicing programming fundamentals, logical thinking, and problem-solving.

## Languages

- Python
- C++

These languages are listed in the existing repository documentation. Individual projects may have different setup requirements.

## Getting started

1. Browse the repository and choose a project file.
2. Read the source to understand its inputs and purpose.
3. Install the relevant Python runtime or C++ compiler.
4. Run the selected project according to its language and any dependencies.

Because this repository contains multiple mini projects, there is no single run command that applies to every file. Add project-specific commands as each project is documented.

## Goals

- Practice programming fundamentals.
- Improve logical thinking and problem-solving.
- Experiment with small ideas and utilities.
- Track learning progress through code.
